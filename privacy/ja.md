# Veiler プライバシーポリシー

**制定日: 2026年7月15日**
**最終改定日: 2026年8月21日**

本プライバシーポリシー（以下「本ポリシー」といいます）は、Hiroki Kataoka（以下「当方」といいます）が提供する iOS アプリ「Veiler」（以下「本アプリ」といいます）における利用者の情報の取り扱いについて定めるものです。本アプリをご利用いただく前に、本ポリシーをお読みください。

本アプリは、写真・動画・書類を端末内に保管し、パスコードや生体認証（Face ID 等）でロックして管理するためのアプリです。本アプリは利用者のアカウント登録を必要とせず、当方は本アプリのための独自サーバーやデータベースを一切運用していません。保管された写真・動画・書類は、利用者の端末内に保存されます。有料プラン「Veiler Pro」で iCloud 同期をオンにした保管庫については、暗号化したコピーが利用者ご自身の iCloud にも保存されます（5. をご覧ください）。また、無料プランでは本アプリ内に広告を表示します（2.3 をご覧ください）。

## 2. 当方が取得する情報

### 2.1 保管したデータ — 当方のサーバーへは送信されません

本アプリは、利用者が保管する写真・動画・書類、およびそれらのタイトル・アルバム等の整理情報を、利用者の端末内に保存します。当方は本アプリのためのサーバーを運用しておらず、これらのデータが当方へ送信されることは一切ありません。

利用者が有料プラン「Veiler Pro」で iCloud 同期をオンにした保管庫に限り、その中身（写真・動画・書類、およびタイトル・アルバム等の整理情報）を暗号化したコピーが、利用者ご自身の Apple ID に紐づく iCloud 内の本アプリ専用領域に保存されます。同期は保管庫ごとに利用者が選択するもので、既定ではオフです。詳細は 5. をご覧ください。

当方は、利用者の行動を分析するためのアナリティクス SDK やクラッシュレポート SDK を本アプリに組み込んでおらず、利用者の閲覧内容・アプリ内の操作履歴を収集・保有することはありません。他方、本アプリは課金管理のための SDK（2.2）と、無料プランにおける広告表示のための SDK（2.3）を利用しており、これらの提供事業者が各社の定めに従って取得する情報については、それぞれの項をご覧ください。

### 2.2 例外 — サブスクリプション課金に関する情報

本アプリの有料プラン「Veiler Pro」を購入・復元する場合に限り、課金管理のため第三者サービス RevenueCat（RevenueCat, Inc.）の SDK を利用します。この際、以下の情報が RevenueCat のサーバーに送信・保管されます。

- Apple の App内課金（In-App Purchase）を通じた購入レシート・購入／解約・トライアルの状態などの購入履歴
- 本アプリが課金状態を紐づけるために用いる匿名のアプリ利用者 ID（氏名・メールアドレス等の個人を直接特定する情報とは結び付いていません）
- 課金処理に付随するデバイス情報（デバイスの種別、OS バージョン、大まかな地域など）

これらは有料機能の提供・購入の復元・不正防止のために用いられ、当方が広告配信やプロファイリングの目的で利用することはありません。RevenueCat における情報の取り扱いは、RevenueCat のプライバシーポリシー（https://www.revenuecat.com/privacy/ ）に従います。

なお、購入代金の決済そのものは Apple（App Store）が処理します。当方および RevenueCat が、利用者のクレジットカード番号等の決済手段の情報を受け取ることはありません。

### 2.3 広告の表示に関する情報

無料プランでは、本アプリ内に広告を表示します。広告の配信には Google の広告サービス「Google AdMob」（Google LLC）の SDK を利用しており、広告の配信・表示回数の計測・不正防止のために、以下のような情報が Google に送信されます。

- 広告識別子（IDFA）等のデバイス識別子（IDFA は、利用者が iOS の「トラッキングの許可」の確認で許可した場合にのみ利用されます）
- IP アドレスから推定される大まかな位置（国・地域の水準であり、GPS による正確な位置情報は取得しません）
- デバイス情報（デバイスの種別、OS バージョン等）、広告の表示・タップ等の利用状況、および広告 SDK の動作に関する診断情報

これらの情報は Google が同社のプライバシーポリシーに従って取り扱い、広告の配信・測定のほか、Google および同社の広告パートナーによるパーソナライズ広告の表示に用いられる場合があります。詳細は Google のプライバシーポリシー（https://policies.google.com/privacy ）および「Google のサービスを利用するパートナーによるデータ使用」（https://policies.google.com/technologies/partner-sites ）をご覧ください。

**広告 SDK が、利用者が本アプリに保管した写真・動画・書類、およびそれらのタイトル・アルバム名を読み取ることはありません。** 当方が広告に関して受け取るのは、表示回数・収益等の集計値のみであり、個々の利用者を識別できる形の情報を当方が受け取ることはありません。

広告に関する利用者の選択肢は次のとおりです。

- 欧州経済領域（EEA）・英国等の対象地域では、Google の同意管理ツール（UMP）による同意画面を表示します。同意されない場合は、パーソナライズされていない広告が配信されます。
- iOS の「トラッキングを許可しますか？」の確認で「許可しない」を選択された場合、IDFA は利用されません。この設定は iOS の「設定 > プライバシーとセキュリティ > トラッキング」からいつでも変更できます。
- 有料プラン「Veiler Pro」をご利用の場合、広告は表示されず、広告 SDK の初期化および広告配信のための情報送信も行われません。

### 2.4 利用状況の記録（アプリ改善のための計測）

本アプリは、どの機能が使われたか（例: 取り込みの完了、設定画面の表示）を、あらかじめ定めた項目名のみで記録します。送信には Google アナリティクス for Firebase および Firebase Crashlytics（いずれも Google LLC・米国）を利用します。アプリが正常に動作しなかった場合には、その種類と発生箇所（プログラム上の情報）も記録します。

保管庫の中身・ファイル名・アルバム名・枚数が送信されることは一切ありません。個人を識別する情報とは結び付けず、広告識別子（IDFA）とも結び付けません。この記録は、本アプリの設定画面（「アプリについて」内の「利用状況の送信」）からいつでも停止できます。

### 2.5 ご意見・お問い合わせの送信

本アプリ内の「ご意見・お問い合わせ」から送信いただいた場合に送信されるのは、入力いただいた本文と、アプリのバージョン・iOS のバージョン・端末の機種名のみです。個人を識別する情報を含まないため、当方から返信することはできません。保存先は Google Cloud Firestore（Google LLC・米国）です。

## 3. 利用目的

当方は、2.2 に記載した課金関連情報を、次の目的の範囲でのみ利用します。

- 有料プラン「Veiler Pro」の提供、および有料機能の有効化・無効化
- 機種変更・再インストール時における購入の復元
- 課金に関する不具合対応、不正利用の防止
- 法令の遵守、および利用規約の履行

2.3 に記載した広告関連の情報は、無料プランを広告収益によって提供するために、広告の配信・表示・測定および不正防止の目的で Google において利用されます。当方はこれらの情報を用いて利用者個人を特定することはせず、また他の情報と照合することもありません。

## 4. 第三者への提供・委託

当方は、取得した情報を第三者に販売・貸与することはありません。また、法令に基づく場合を除き、第三者へ提供することはありません。

課金機能の提供のために、以下の事業者に処理を委託しています。これらは当方の指定する目的の範囲で情報を取り扱います。

- Apple Inc.（App Store / In-App Purchase）: 決済処理、サブスクリプションの提供・更新・解約。取り扱う情報は購入・課金に関する情報（決済手段の情報は Apple が保有し当方は受領しません）。
- RevenueCat, Inc.: サブスクリプション状態の管理・購入の復元。取り扱う情報は 2.2 に記載した購入履歴・匿名の利用者 ID・デバイス情報。
- Google LLC（Google AdMob）: 無料プランにおける広告の配信・測定。取り扱う情報は 2.3 に記載したデバイス識別子・大まかな位置・デバイス情報・広告の利用状況。Google は、これらの情報を自社および広告パートナーの広告配信のために、自社のプライバシーポリシーに基づき独立して取り扱います。
- Google LLC（Firebase: Google アナリティクス / Crashlytics / Cloud Firestore）: 2.4 に記載した利用状況・動作不良の記録の集計、および 2.5 に記載したお問い合わせ内容の保管。

上記委託先のサーバーは日本国外（米国等）に所在する場合があります。これらの事業者は、自社のプライバシーポリシーおよび適用される法令に従って情報を取り扱います。

## 5. データの保存場所と保存期間

- 利用者が本アプリに保管した写真・動画・書類および整理情報は、利用者の端末内（本アプリ専用の保存領域）に保存されます。当方のサーバーには保存されません。
- iCloud 同期をオンにした保管庫（Veiler Pro）については、暗号化したコピーが、利用者ご自身の Apple ID に紐づく iCloud 内の本アプリ専用コンテナに保存されます。保存先は利用者ご自身の iCloud であり、当方がその内容を取得・閲覧することはありません。このコピーは、利用者が削除するまで保持されます。
- 端末内の保管データは、iCloud バックアップ・パソコンへのバックアップ等のデバイスバックアップからは除外しています。端末のバックアップに保管庫の中身が複製されることはありません。
- 本アプリを端末から削除（アンインストール）すると、端末内に保存された本アプリのデータはすべて削除されます。ただし、iCloud 同期をオンにしていた保管庫の暗号化コピーは、アンインストール後も利用者の iCloud に残ります（同じ Apple ID で再インストール・サインインした際に復元できるようにするためです）。削除の方法は 6. をご覧ください。
- 2.2 の課金関連情報は、購入の管理・復元に必要な期間、Apple および RevenueCat において保管されます。
- 2.3 の広告関連情報の保存期間は、Google の定めるところによります。

保護について: 本アプリの現行バージョンは、端末内の保管ファイルを本アプリ独自の暗号化により暗号化するものではなく、端末内の専用領域に保存したうえで、本アプリのパスコード・生体認証によるロックと、iOS が提供する標準の端末保護（端末パスコードによる保護等）に依拠しています。より強固な保護のため、端末自体にパスコードを設定してご利用ください。

一方、iCloud へアップロードするコピーは常時暗号化しています。これはクラウド上に暗号化されていないファイルを置かないための措置であり、利用者の iCloud アカウントにアクセスできる者に対して内容を秘匿することを保証するものではありません。

## 6. 利用者の権利と選択

- データの閲覧・持ち出し: 保管したデータは、本アプリのエクスポート機能および OS の共有機能を通じて、いつでも取り出すことができます。
- データの削除: アプリ内で個別に削除できるほか、本アプリを端末から削除することで、端末内の本アプリのデータをすべて削除できます。
- iCloud 上のコピーの削除: iCloud 同期をオンにした保管庫の暗号化コピーは、iOS の「設定」＞（ご自身の名前）＞「iCloud」＞「アカウントのストレージを管理」から Veiler を選び、データを削除することで消去できます。アプリのアンインストールだけでは消去されません。ご不明な点は 1. のお問い合わせ先までご連絡ください。
- 利用状況の記録について: 2.4 に記載した記録は、本アプリの設定（「アプリについて」＞「利用状況の送信」）からいつでも停止できます。
- 広告について: 2.3 に記載した方法（iOS のトラッキング設定の変更、対象地域における同意画面での選択、Veiler Pro のご購入）により、広告のための情報の利用を制限できます。
- ゴミ箱の挙動: 削除したアイテムは、プランに応じてゴミ箱に一定期間（Veiler Pro では最大 30 日間）保持された後に完全に削除されます。無料プランでは削除は即時に反映されます。ゴミ箱内のデータも、アプリを削除すれば失われます。
- 課金情報について: 課金・購入履歴に関する情報の確認・管理は、Apple の App Store アカウント設定、および必要に応じて 1. のお問い合わせ先を通じて行えます。

## 7. 生体認証（Face ID 等）の取り扱い

本アプリは、ロック解除の手段として端末の生体認証（Face ID／Touch ID 等）を利用できます。生体認証の照合は端末の OS 内で完結し、本アプリが顔・指紋などの生体情報そのものを取得・保存・送信することは一切ありません。本アプリは、OS から「認証に成功したか否か」の結果のみを受け取ります。
